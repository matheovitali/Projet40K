# Projet40K — Asset repository for a tabletop companion project

**Public graphics repository · Not the Unity application source**

This repository contains **image assets and UI graphics** associated with an ongoing personal Unity/C# tabletop role-playing companion project. Its current public contents are organized into folders such as `Borders/`, `Grot/`, `Merchant/`, `Players/` and `SpaceMarine/`.

**It does not contain the Unity application, gameplay logic, networking code or tests.** Please do not evaluate it as a complete playable application or a source-code portfolio.
