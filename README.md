# Projet40K

This repository contains artwork and UI assets for a tabletop RPG companion app I'm building in Unity and C#. You'll find graphics in folders such as `Borders/`, `Grot/`, `Merchant/`, `Players/` and `SpaceMarine/`.

The actual Unity application, multiplayer code and tests aren't included here, and there's no public build yet.

For more about the technical side of the project, see [my Unity project write-up](https://github.com/matheovitali/matheovitali/blob/main/projects/unity-rpg-companion.md).

This is an unofficial fan project with no publisher affiliation. Some artwork and names may belong to third parties, so nothing in this repository should be assumed free to reuse. No license or redistribution permission is granted here.
